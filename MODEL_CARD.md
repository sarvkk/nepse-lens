# Model card — NEPSE Lens

## Overview

NEPSE Lens contains three model families, each with a different job and a different failure mode. None of them is investment advice.

| Component | Model | Output |
| --- | --- | --- |
| Direction | Histogram gradient boosting, logistic regression, naive prior | P(next session closes up) |
| Anomaly | Robust z-score, Isolation Forest, LSTM autoencoder | Anomaly score + flag per symbol-session |
| Sentiment | Finance lexicon; optional FinBERT | Score in [-1, 1] + positive/negative/neutral |

## Intended use

- Demonstrating an end-to-end market-intelligence pipeline: ingestion, point-in-time features, walk-forward evaluation, NLP, serving, and visualization.
- Research and teaching on Nepali equity data and financial-news sentiment.
- A starting point for a production system, not a production system.

## Out of scope

- Trading, portfolio construction, or any decision with money at risk.
- Claims about NEPSE returns. The bundled prices are synthetic.
- Regulatory or compliance use.

## Training data

**Prices.** `data/fixtures/nepse_daily.csv` is generated by `ingest/fixtures.py` with a fixed seed (7): 59 symbols, 10 sectors, 760 business-day sessions ending 2026-11-25. Returns are a market factor plus a sector factor plus idiosyncratic noise, with an AR(1) momentum term and rare jumps. Volume is lognormal and scales with absolute return. 118 anomaly events are injected.

**Headlines.** 3,422 templated NEPSE-style headlines with ground-truth sentiment labels, plus negation and mixed-signal hard cases. This is a pipeline smoke test, not a natural-language corpus.

**Benchmark.** Financial PhraseBank v1.0, `Sentences_AllAgree` (2,264 sentences), Malo et al. (2014), CC BY-NC-SA 3.0. Downloaded at runtime, not vendored.

## Limitations

1. **Synthetic prices.** The direction result validates the harness, not the market. The generator's AR(1) term creates a small, known signal; real NEPSE data will be noisier.
2. **Injected anomalies.** Detectors recover deliberately extreme volume/return spikes. Real anomalies are subtler and rarer.
3. **No corporate actions.** Splits, bonuses, and rights issues are not adjusted in the fixture.
4. **No costs or liquidity.** There is no spread, brokerage fee, circuit breaker, or capacity model.
5. **Headline-only sentiment.** No article body, no entity linking, no source credibility weighting.
6. **Neutral-class collapse.** The lexicon's neutral band is crude; FinBERT still needs calibration for the neutral class.
7. **Survivorship.** The universe is fixed; delisted or merged NEPSE symbols are absent.

## Ethical and operational notes

- Do not present these outputs as recommendations to retail investors.
- Financial-news sentiment can encode source bias; a production system should log source-level error rates.
- Any deployment should include human review for anomaly alerts and a clear "model, not advice" disclosure.

## Reproduction

```bash
pip install -e ".[dev]"
python scripts/fetch_data.py --source fixture
python scripts/train.py
python scripts/fetch_phrasebank.py
python scripts/evaluate.py
```

Deterministic seeds: fixture `7`, Isolation Forest `42`, gradient boosting `42`, PyTorch `42`.
